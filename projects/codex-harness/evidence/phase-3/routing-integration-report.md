# Routing integration report

The bridge is implemented by `Phase3RouterBridge`. It converts only selected,
eligible observed records into the existing immutable Phase 2 registry and
calls the pure `minimum_route()` policy. It preserves project/workspace/global
origin precedence, capability status, declarative contracts, compatibility,
trust and stop conditions. Record iterables are bounded before materialization.

The routing smoke in `routing-integration.json` selected the project-local
`harness-kernel` metadata record. `execution` is `not invoked`; unresolved
classification/evidence signals remain visible and are not silently promoted.
The real-host cross-agent smoke routes installed `design-director` and ECC
conventions when eligible and explicitly blocks the divergent
`engineering-framework` duplicate.
