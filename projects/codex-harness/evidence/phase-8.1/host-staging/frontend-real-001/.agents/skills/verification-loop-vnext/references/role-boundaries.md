Load when: the requested action, actor or report authority could cross a role boundary.

VERIFIER owns factual checks and bounded status reports. BUILDER creates or
repairs artifacts. DESIGN_DIRECTOR owns visual strategy. REVIEWER independently
compares observations with the quality bar. ASSURANCE owns stop or continue
risk decisions. ORCHESTRATOR owns delegation. RELEASE_AUTHORITY owns delivery
approval. These roles remain separate even when a router places them in one
pipeline.

Block builder self-approval, verifier mutation, criteria redefinition and any
request to issue visual, assurance or release approval. A verifier can report
that a fact is unobserved; it cannot turn that limitation into permission.
